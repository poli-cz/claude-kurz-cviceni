# NG-SA-2026-014: Authentication bypass in Northgate VPN Gateway web portal

> Smyšlené oznámení pro kurz. Výrobce, produkt ani identifikátor neexistují.

- **Published:** 2026-11-10
- **Severity:** Critical (CVSS 3.1 base score 9.8)
- **Identifier:** NG-2026-3107
- **Exploitation:** Exploitation in the wild has been observed.

## Affected versions

| Branch | Affected | Fixed in |
|---|---|---|
| 7.5.x | 7.5.0 through 7.5.2 | 7.5.3 |
| 7.4.x | 7.4.0 through 7.4.5 | 7.4.6 |
| 6.9.x | all versions (end of support) | no fix, upgrade to 7.5.3 |

Branch 7.6.x is not affected.

## Description

A crafted request to the SSL VPN web portal allows an unauthenticated remote attacker to obtain an administrative session.

## Workaround

Until the update is installed, disable the web portal on external interfaces (`set portal external disable`) or restrict it to trusted source addresses.

## Indicators of compromise

Log entries with `portal_session created user=""` and unexpected local administrator accounts.
