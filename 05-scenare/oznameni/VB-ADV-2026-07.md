# VB-ADV-2026-07: Privilege escalation in Velden Backup Agent for Windows

> Smyšlené oznámení pro kurz. Výrobce, produkt ani identifikátor neexistují.

- **Published:** 2026-11-13
- **Severity:** High (CVSS 3.1 base score 7.8)
- **Identifier:** VB-2026-0193
- **Exploitation:** Proof of concept is public.

## Affected versions

Velden Backup Agent for Windows 12.0.0 to 12.0.8 inclusive. Versions 11.x are not affected because the vulnerable update service was introduced in 12.0.0. Fixed in 12.0.9 and 12.1.0.

## Description

The agent update service loads a library from a directory writable by local users. A local user can execute code as SYSTEM.

## Mitigation

Upgrade to 12.0.9 or later. As a temporary measure remove write permission for `Users` on `C:\ProgramData\Velden\Agent\updates`.
