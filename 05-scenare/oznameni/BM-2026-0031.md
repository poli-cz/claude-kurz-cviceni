# BM-2026-0031: Header injection in Brightmail Secure Relay

> Smyšlené oznámení pro kurz. Výrobce, produkt ani identifikátor neexistují.

- **Published:** 2026-11-12
- **Severity:** Medium (CVSS 3.1 base score 5.3)
- **Identifier:** BM-2026-0031
- **Exploitation:** No known exploitation.

## Affected versions

All 3.x releases before 3.9.4 and 4.0.x releases before 4.0.3. Release 4.1.0 and later is not affected.

## Description

An authenticated sender can inject additional SMTP headers through the display name field, which may bypass downstream filtering rules.

## Remediation

Upgrade to 3.9.4, 4.0.3 or later. No workaround is available. The update requires a restart of the relay service (about two minutes of mail queueing).
